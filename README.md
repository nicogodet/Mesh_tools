# Mesh Tools 
Tools for management of data using Mesh format for Telemac or Uhaina
More informations on Telemac could be found on [Open Telemac-Mascaret website]("http://www.opentelemac.org/")
More informations on Uhaina could be found (soon) 

## Installation
Use the QGIS Plugins menu to install the Mesh Tools Plugin

## Culvert Manager

Prepares the culverts of a TELEMAC (`CULVERTS DATA FILE`) or Uhaina model from a line layer.

1. Choose the mesh layer and the dataset giving the bottom elevation.
2. Create a culvert layer (shapefile or GeoPackage) or import an existing culvert file (TELEMAC: nodes `I1 I2`,
   tab or space separated; Uhaina: coordinates `X1 Y1 X2 Y2`).
3. Draw the culverts from extremity 1 to extremity 2 and fill their parameters with the attribute form
   ("Edit the culvert…" in the panel). The nodes, and the elevations, length and angles set to automatic, are
   updated by the form whenever a culvert is modified.
4. Choose the software, the TELEMAC `OPTION FOR CULVERTS` (1 or 2: the form only shows the parameters it uses) and the
   relaxation, then "Check" and "Create culvert file…". Nodes and automatic values are always computed again for the
   file.

**New or renumbered mesh.** To update a culvert file after the mesh was renumbered (or remeshed): import the file
with the mesh it was made for, select the new mesh, then "Create culvert file…": only the nodes change, the panel
says how many culverts got new nodes, and warns when an extremity is no longer on a node (the mesh geometry changed).
The Processing algorithm *Renumber culvert file for another mesh* does it in one step, from file to file, keeping the
file as written except the nodes.

The fields have the TELEMAC names (`I1 I2 CE1 CE2 CS1 CS2 LRG HAUT1 CLP LBUS Z1 Z2 CV C56 CV5 C5 CT HAUT2 FRIC LENGTH
CIRC D1 D2 A1 A2 AA`, plus `NAME`, `AL`, `AZ` and `NB_in_//` for Uhaina). Layers made by older versions (`N1`, `LARG`,
`HAUT`, `CLAP`, `L12`...) are still read.

The mesh, the bottom dataset, the culvert option and the relaxation are stored in the culvert layer and in its default
style (inside the GeoPackage, or a `.qml` next to a shapefile).

The same operations are available as Processing algorithms (provider *Mesh Tools*: import culvert file, check
culverts, export culvert file, renumber culvert file for another mesh), and the expression functions `mesh_vertex_index()` and `mesh_vertex_value()` query a
mesh from any layer while the plugin is loaded.

## Development
Some makefile methods require to install few dependecies.

For translations `make transup` and `make transcompile`:

```bash
apt install qttools5-dev-tools pyqt5-dev-tools
```

The style of the culvert layers is generated by `scripts/make_culvert_style.py` (run it with the Python of QGIS from
the repository root).

Tests: `pytest tests/unit` (no QGIS needed) and, for the QGIS tests, in a QGIS Docker image:

```bash
docker run --rm -v $PWD:/repo -w /repo -e QT_QPA_PLATFORM=offscreen \
  -e PYTHONPATH=/usr/share/qgis/python:/usr/share/qgis/python/plugins \
  qgis/qgis:3.44 python3 -m unittest discover -s tests/qgis -t . -p "test_*.py"
```

For code formating `make black`:

```bash
pip install black isort
```
